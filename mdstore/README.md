# mdstore

`mdstore` is a Git-backed Markdown daemon for validated search and editing over MCP. Documents, root `config.yaml`, and directory `schema.md` files are canonical; templates define document structure, relationships, link syntax, and change rules. Embedding sidecars are disposable and must be ignored by Git. Build with `nix develop .#mdstore --command cargo build --manifest-path mdstore/Cargo.toml`, then run `mdstore --root /path/to/repository serve`. Configure retrieval, Git synchronization, and the listen address in `config.yaml`; deploy behind trusted network access controls.

MCP exposes `read`, `search`, and `edit`. Reads return a snapshot commit and numbered hashline anchors; HTTP source reads expose the commit in `X-Mdstore-Commit`. Edits use those anchors; atomic moves additionally require `expected_commit`. Edits address original paths, then moves apply simultaneously, supporting chains, swaps, and explicitly vacated destinations. The server preserves document identity while rewriting Markdown/wiki links and rebasing relative assets, leaving labels, fragments, provenance, URLs, and code examples intact. Ambiguous rewrites, collisions, and invalid final schemas reject the batch. Successful edits, moves, backlinks, and deletions publish in one Git commit with retry receipts. See the MCP tool schemas for request details and the [task template](examples/tasks/v1/schema.md) for schema examples.
